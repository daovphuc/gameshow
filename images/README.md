# Thư mục hình ảnh (`images/`)

Đặt hình ảnh của các đội thi và hình minh họa câu hỏi vào thư mục này rồi commit lên GitHub. Sau đó, trong trang **Cấu hình nội dung** (`content.html`), nhập **tên file** vào ô ảnh tương ứng:

- Ảnh đội thi (tab Đội thi): ví dụ `doi-01.jpg`, `doi-02.png`
- Ảnh câu hỏi Vòng 1: ví dụ `v1-doi-01-a.jpg`
- Ảnh câu hỏi Vòng 3: ví dụ `v3-cau-05.png`

Ô ảnh cũng nhận một link `https://...`. Nên dùng ảnh nhỏ (dưới khoảng 300 KB) để iPad tải nhanh.

Nếu ô ảnh để trống hoặc file ảnh không tồn tại, hệ thống sẽ tự động hiển thị chữ viết tắt tên đội (không hiện biểu tượng ảnh lỗi).
