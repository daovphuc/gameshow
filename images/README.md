# Thư mục hình ảnh (`images/`)

Đặt hình ảnh của các đội thi và hình minh họa câu hỏi vào thư mục này, sau đó điền **tên file** vào cột `image_url` trên Google Sheet:

- Ảnh đội thi (tab `teams`): ví dụ `doi-01.jpg`, `doi-02.png`
- Ảnh câu hỏi Vòng 1 (tab `round1`): ví dụ `v1-doi-01-a.jpg`
- Ảnh câu hỏi Vòng 3 (tab `round3`): ví dụ `v3-cau-05.png`

Nếu ô `image_url` để trống hoặc file ảnh không tồn tại, hệ thống sẽ tự động hiển thị chữ viết tắt tên đội (không hiện biểu tượng ảnh lỗi).
